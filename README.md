# College Canteen Food Ordering System

## 📌 Overview
A web-based application designed to reduce congestion at college canteens by allowing students to order food online and track order status.

## 🚀 Features
- Student Registration & Login
- Online Food Menu & Cart
- Order Placement & Tracking
- Admin Panel for Order Management
- QR Code Based Menu Access

## 🛠️ Technologies Used
- HTML, CSS, Bootstrap
- PHP
- MySQL
- XAMPP

## 🖥️ How to Run
1. Install XAMPP
2. Place project in `htdocs`
3. Start Apache & MySQL
4. Import database
5. Open `http://localhost/canteen-app/`
